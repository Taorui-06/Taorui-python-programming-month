## 二、四周计划

| 周次 | 日期 | 必须掌握的知识 | 练习要求 | 阶段成果 |
| --- | --- | --- | --- | --- |
| week1 | 10-20 ~ 10-26 | 环境与运行、变量与基本数据类型、输入输出与类型转换、算术/比较/逻辑运算、`if-elif-else`、`for` / `while` / `range()`、循环嵌套、阅读常见错误信息 | ≥ 15 道基础练习 | 基础练习、学习记录、第一次检查 |
| week2 | 10-27 ~ 11-02 | 字符串及常用方法、列表/元组/字典/集合、遍历查找排序统计去重、函数定义与调用、参数返回值与作用域、列表推导式、用函数拆分程序 | 新增 ≥ 15 道 | 函数与数据组织练习、第二次检查 |
| week3 | 11-03 ~ 11-09 | 文本文件读写、CSV / JSON 基础、`try-except`、模块导入与自定义模块、程序目录组织、类与对象基础、基础调试与测试 | 新增 ≥ 10 道 | 综合练习、问题记录、第三次检查 |
| week4_review | 11-10 ~ 11-19 | 按「基础语法—分支循环—函数—字符串—列表与字典—文件—异常—模块」整理知识清单 | ≥ 10 道综合题 + 90 分钟限时模拟 | 限时模拟、查漏补缺、最终考核 |

每周练习题由对接的高年级同学分阶段发放，不在本仓库公开发布题目原文。

**运行环境**

- Python 3.13（`python --version`）
- Git 2.56
- 编辑器：VS Code
- 操作系统：Windows

**代码约定**

- 每道练习题单独一个 `.py` 文件，命名为 `题目_序号.py`，例如 `week1/calc_01.py`
- 每个文件顶部用注释注明：第几周、题目要求、测试数据
- 不提交 `__pycache__/`、虚拟环境目录等自动生成文件（见 `.gitignore`）

## 四、提交规范

- 每周至少 3 次有效提交，四周不少于 12 次
- 提交分布在不同日期，禁止截止前一次性上传
- 提交说明写清完成或修改的内容，不写「更新」「完成」「最终版」
- 保留失败版本和问题记录，不删除历史来伪造一次成功

格式：`前缀(第几周): 具体做了什么`

| 前缀 | 用途 | 示例 |
| --- | --- | --- |
| `feat` | 新增练习代码 | `feat(week1): 完成温度转换练习` |
| `fix` | 修正出错代码 | `fix(week2): 修正循环边界越界` |
| `docs` | 更新日志文档 | `docs: 补充第 1 周学习记录` |
| `chore` | 配置类改动 | `chore: 添加 .gitignore` |
